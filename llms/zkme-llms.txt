# zkMe

> zkMe is a decentralized identity network delivering privacy-preserving compliance for Web3. Using zero-knowledge proofs, SSI wallets and soulbound tokens, integrators verify their users (zkKYC, zkOBS), businesses (zkKYB) and screen on-chain activity (KYT) without ever handling raw personal data. Verification runs client-side through embeddable widgets; results are queried through the zkMe Open API.

## APIs

- [zkMe Protocol API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/zkme/refs/heads/main/openapi/zkme-openapi.yml): zkKYC, zkOBS, zkKYB and KYT result/query endpoints on https://agw.zk.me
- [API integration docs](https://docs.zk.me/hub/start/onboarding/integration/api): endpoint reference, auth, rate limits
- [Access-token service](https://nest-api.zk.me/api/token/get): mints the short-lived SDK access token

## Products

- [zkKYC](https://docs.zk.me/hub/start/onboarding/integration/api/verify-zkkyc): customer identity, sanction, age, citizenship, location and uniqueness proofs
- [zkKYB](https://docs.zk.me/hub/start/onboarding/integration/api/zkkyb): business entity + UBO verification
- [zkOBS](https://docs.zk.me/hub/start/onboarding/integration/api/verify-zkobs): open-banking proof of accredited investor / proof of address
- [KYT](https://docs.zk.me/hub/start/onboarding/integration/api/get-kyt): wallet-address and transaction risk screening

## SDKs

- [@zkmelabs/widget](https://www.npmjs.com/package/@zkmelabs/widget): zkKYC and Anti-Sybil verification widget
- [@zkmelabs/kyb-widget](https://www.npmjs.com/package/@zkmelabs/kyb-widget): zkKYB business-verification widget
- [Mobile SDK](https://docs.zk.me/hub/start/onboarding/integration/mobile-sdk): native mobile verification
- [GitHub org](https://github.com/zkMeLabs): DID registry/resolver, zkTLS SDKs, circuits and contracts
